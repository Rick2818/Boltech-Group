# Mensaje personalizado

Use the company name and observed process category to select a relevant subject and question. Refer only to the public process; ask whether it needs help. Keep customer need unconfirmed. Offer evaluation in writing, without invented metrics, prices, meetings or delivery commitments. Include an easy stop option. Persist the candidate and read it back; preparation is not a send receipt.

## Execution

Use `lib/agent1_sales_skills.js`, method `prepare` through the existing Agent 1 worker. The runtime uses deterministic rules and zero model calls. Read `docs/commercial/AGENT1_SALES_SKILLS.md` for bindings, durable state, tests and current limits. Do not treat this Markdown file as an independently deployed service.
