# Calificación BANT

Record all four BANT dimensions as UNKNOWN during cold preparation. A public role is not verified purchasing authority; an RFQ page is not confirmed need. Ask about one current process in writing. Let Agent 2 verify customer statements against the actual reply before qualification. Never convert silence or website content into budget, urgency or willingness to pay.

## Execution

Use `lib/agent1_sales_skills.js`, method `prepare` through the existing Agent 1 worker. The runtime uses deterministic rules and zero model calls. Read `docs/commercial/AGENT1_SALES_SKILLS.md` for bindings, durable state, tests and current limits. Do not treat this Markdown file as an independently deployed service.
