## Regla de arquitectura

El runtime productivo permanece en las carpetas existentes de Boltech Group. Este paquete contiene estrategia, catálogo, evidencia, guías, copy y configuración comercial; no crea un segundo runtime ni reactiva cold email.

## Integraciones

- Leo conserva aprobación humana para acciones sensibles.
- Wompi no se modifica.
- Upwork y Freelancer permanecen read-only hasta certificación y autorización.
- Explee no se activa sin credenciales y prueba autenticada.
- Supabase sigue siendo la fuente de verdad solo después de aplicar y verificar sus migraciones.
